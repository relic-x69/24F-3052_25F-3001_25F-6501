# Chess Game in C++

This is a two-player console-based Chess Game developed in C++ for an Object-Oriented Programming semester project.

The game includes:
- 8x8 chessboard
- Turn-based gameplay
- Piece classes for Pawn, Rook, Knight, Bishop, Queen, and King
- Valid move checking
- Possible move display
- Check and checkmate detection
- Stalemate detection
- Castling
- En passant
- Pawn promotion

## How to Run

Open the project in Visual Studio Community and run `main.cpp`.
